1. **写交易只跑一次**：`deploy / register / activity` 会真实消耗燃料并留下记录；演示只用只读命令（`credit / query / account`）。
2. **查询认准链 ID `a00e36c5`**：控制台/浏览器里若选到 `141a…2553（合约体验版）`，会显示"查无此交易"或看到无关的 `cloud-ide-test-account-…`。
3. **私钥不出文件夹**：`keys/access.key` 只在本机演示使用，参赛提交压缩包前删除。

## 四、常见卡点速查

| 现象                              | 原因                            | 解决                                      |
| ------------------------------- | ----------------------------- | --------------------------------------- |
| `找不到或无法加载主类 TeachFlowTool`      | 没在项目文件夹里跑                     | 先 `cd` 到项目根目录                           |
| `fail check signature`          | AccessKey ID 与 access.key 不配对 | 回控制台核对 AccessKey ID（本表信息 1）             |
| `209 no business authorization` | bizid 选错（用了体验链）               | 改回 `a00e36c5`                           |
| `211 rate limit reached`        | 查询太频繁                         | 等几秒重试                                   |
| 交易失败且 gas 不退                    | gas 设太小                       | 交易 gas 设 ≥ 100000（本工具默认 300000/500000）  |
| 浏览器查不到交易                        | 链选错                           | 选「开放联盟链 a00e36c5」                       |
| 视觉大屏查询返回空                       | 服务工作目录不对                      | 用项目根启动 `python 可视化\visualize_server.py` |
