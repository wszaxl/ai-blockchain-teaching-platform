# 大赛要求（原图 OCR，已人工分段整理）

来源：用友·新道「区块链技术开发实践（技术创新组）」赛题图片。

## 1. 技术开发实践选题范围
- 可涉及但不限于金融、供应链、双碳、医疗、司法等领域；
- 鼓励「区块链 + AI」应用类选题；
- 请勿与 ICO 和虚拟货币关联。

## 2. 提交资料（三个都要）
1. 方案 PPT；
2. PDF 格式技术文档；
3. 视频——内容包括：联盟链搭建过程视频、智能合约运行视频、SDK 运行视频。

## 3. 技术文档内容（PDF 必须包含）
- 业务痛点；
- 行业发展趋势；
- 解决方案：流程、关键技术、区块链应用点、
  区块链网络拓扑图、创新业务流程图、上链数据分析图；
- 智能合约。

## 4. 技术开发实践内容
- 上链数据设计；
- 智能合约开发；
- 使用 SDK 调用智能合约。
- 智能合约语言：推荐 Solidity、Vyper、Go 等；
- 代码结构要清晰，关键部分需添加注释，说明功能、算法和核心逻辑；
- 注释内容必须与代码严格对应；
- 复杂合约需定义接口文档，规范合约间交互关系。
- 区块链网络搭建：包括主网络、从网络、节点、通道等主要步骤。

## 5. 图中示例（供应链金融业务，仅作图例参考）
云友信开立阶段 → 云友信流转、签收阶段 → 云友信融资阶段；
多级流转：核心企业 ↔ N级供应商 ↔ 平台融资 ↔ 保理公司 ↔ 资金方；
网络示意：超级节点 / peer 节点 / 半分布式网络。
